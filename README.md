### `//` About Me

I'm a **Full-Stack AI Engineer** and **Informatics Engineering student** at **Jakarta State Polytechnic** (`GPA 3.96 / 4.00`), focused on building intelligent, data-driven web applications and high-performance backend systems. Over the past 3+ years, I've delivered end-to-end digital products for ~10 freelance and enterprise clients—ranging from international e-commerce platforms to machine learning analytics dashboards.

- 🔭 **Currently working on:** Scalable full-stack web systems & AI-powered analytics dashboards
- 💼 **Experience:** Fullstack Developer @ **Flowhomme.id** *(Korea, Remote)* · Freelance @ **ZhennLabs** · Former Intern @ **Kompas Gramedia**
- 🏆 **Recognition:** 1st Place National Static Web Dev Competition (2024) · Published in **SISKOM-KB (SINTA 4)**
- ⚡ **Focus areas:** Backend Architecture (`Golang`, `Laravel`, `Python`), Modern Frontend (`React.js`, `Tailwind CSS`), & Applied ML/NLP
